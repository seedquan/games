# 弹反的有限动画图解

Status: implemented

## Context

修正输入后的正常规则长枪与双人火焰法杖机器人能通过三十舱，但机器人读取精确弹道，不代表新玩家理解弹反时机。首舱引导只有移动、攻击与冲刺；旧指南的图形也没有展示返弹，只在文字中解释。

## Decision

在新版操作指南顶部加入本地原创 SVG 图解：来弹接近机体、短暂护盾、沿原路返还。默认静态，主动播放后最多五秒；可暂停、继续、重播，失焦暂停、隐藏停止，离开指南释放。演示标明慢动作，不是实际战斗计时器，也不生成弹丸或处理技能输入。

沿用已保存的 `story_motion` 偏好，并将设置文案扩为“剧情与指南动画”。关闭后保留静态来回箭头，隐藏播放按钮；无需迁移键名或新增存档字段。当前按键提示通过正常键鼠/手柄标签读取，支持重绑。旧十二舱不显示新版返弹图解。战斗 HUD、伤害、成长、冷却和地图不变。

## Verification

测试从真实暂停菜单打开指南，以非零设备编号的手柄事件播放、暂停与继续；检查战斗时间/耐久/能量/废料/核心/房间随机状态不变，全局随机数不被消费，重绑标签、多尺寸、静态设置及旧版边界。初始缺少演示的失败已复现。原生首次启动断言取样早于动画首次处理帧，记录显示 `processing=true, elapsed=0`；改为等待真实帧后通过，没有改变动画速度或游戏规则。压缩 JPEG 验证 960×600 与 QHD 输出，原始图不加载到图像工具。

这改善了指南的表达，不作为真人学习效果、实体双手柄或所有硬件性能的验收。现有玩法和构筑数值保持原样，0.18.0 的战斗计时仍作为最近的工程样本。

完整源码验证为 28 套 / 27,107 项通过；Mac 原生图解专项 30 项通过，含静态/接触/返还压缩截图与独立性能采样。M4 Pro、2560×1440、240 个活动动画帧的 P50 / P95 / P99 为 8.041 / 12.663 / 15.963 ms，最大 18.009 ms。采样期间没有其他 Godot 测试负载，不据此声明其他硬件性能。231 个运行文件记录于 `builds/qa/source-0190-defense-guide.json`。
