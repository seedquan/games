# 雷霆残影：冲刺起点的延迟电击

状态：implemented

## 决策

冲刺已有冷却成长，却没有独立的局内打法选择。一次性祝福 `dash_echo`
在正常接受冲刺时于起点留下残影，0.6 秒后向半径 150 内的可见敌人造成
35% 基础攻击伤害，再施加一级电击。冻结目标沿用现有霜链规则：向附近
两敌各传导 45% 电击伤害，不消耗冻结；后续火焰仍可接热冲击。

位置、基础攻击与席位在冲刺时固定。场景节点由 `World/Projectiles` 持有，
暂停冻结时间，换房与重开清除；已经出手的残影不因机体离线而取消。
沿用冲刺的正常冷却和完美闪避返还，不另设隐藏冷却。一次接受的冲刺
只产生一次放电；没有持续伤害，不调用主武器命中，不继承元素、汲取或终结。
伤害与二次传导各自检查掩体。电击防护间隔继续由目标自身控制。

固定轮廓按掩体裁切，中心电击符号和单/双席刻线不依赖闪光。
原创 SVG 展示冲刺、短暂等待、原地电击，奖励与构筑复用它；HUD 仅将
该席冲刺名称变为“雷步”。冰霜奖励可提示队友的残影接力，但不把这个
技能误报成主武器电击符文。

## 成长与兼容

沿用 `SKILL_BOONS` 与现有每席 `enchantments`，只允许现代 schema 3 中
显式 ID、整数等级 1。每席只能选择一次；共享选择只装备尚未拥有的队员。
首舱改装、元素商店和承诺的元素奖励保持原范围。旧十二舱不提供或触发
此祝福；旧版读取含新 ID 的现代存档时仍会拒绝并保留只读保护。
奖励上限夹具现在明确装备全部技能祝福，以继续验证只剩一/两项的真实边界。

## 验证范围

核心初次 27 项 / 7 项失败；实现后通过。UI 初次 50 项 / 5 项失败；图示、
构筑与按席 HUD 补齐后通过。冰霜提示的两项失败另行复现并修正。
专属套件通过真实非零手柄事件组合一号新星与二号冲刺，验证单次传导和
双方无友伤；两次隔离冷加载覆盖待选奖励与已装备技能。

输入机器人只选择实际出现的卡，新增可选策略会在冻结目标身旁发起普通
冲刺输入，记录已经爆发的残影数量（不等于命中数）。不改角色、敌人、
奖励或冷却。完整源码回归、正常流程和发行包结果以本版交付记录为准；
不能据受控夹具宣称所有武器的两分钟节奏或真人难度已经验收。
