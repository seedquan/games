# 有边界的范围元素联动

Status: implemented

## Context

用户要求祝福有明显作用并带来意外、有趣的组合。原冰火/火毒只追加单目标伤害；同一武器同时附火毒时，每击立刻消耗一层，无法形成蓄毒策略。

## Decision

仅 campaign 2 增加热冲击半径 150、毒素爆燃半径 185 的范围伤害，分别沿用 70% 火焰命中伤害与每毒层 18% 的反应系数。新版毒素须至少三层才能引爆，保留不同武器攻击次数、蓄力强度、范围与聚怪特点。允许双人用不同武器准备/引爆状态，致命火焰一击也能引爆击杀前已存在的状态。

状态先消费，范围伤害直接调用敌人的伤害入口，不递归附元素、不吸血、不误伤友方。范围与掩体判断从触发敌人中心出发，视觉边界用同一半径；碎冰与燃点通过程序绘制，避免新增外部素材。首领冻结抗性保持原窗口。campaign 1 不改范围、触发层数或存档行为；没有新增持久化字段。

## Verification

`tests/element_reactions.gd` 验证实际伤害、层数消费、致命击、边界/遮挡、双人、首领抗性、十八武器的实际攻击路径和旧版单目标规则。原生模式生成特效/构筑截图并检查重开清理；全套入口纳入此项。输入机器人和发行检查另行记录，受控夹具不代表真人难度验收。
