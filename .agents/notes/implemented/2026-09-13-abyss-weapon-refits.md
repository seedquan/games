# 局内武器改装与第三版续档

状态：implemented

## 背景与选择

局内成长原本只有属性与元素叠加，十八把武器缺少改变操作取舍的强化。本次增加每人每局一个互斥改装槽，覆盖近战、普通/蓄力弹体、回旋刃、连锁闪电和引力井。两张共用方案卡根据各人的武器生成具体收益及代价，双人同选后各自装配，已经装配的一席保留原方案。没有额外战斗按键。首舱优先提供两种方案及正常奖励方向；暂不选择后续仍可抽到。旧十二舱的池与随机调用保持原规则。

改装从原始武器目录深拷贝后生成实际攻击定义，不改全局目录、不重复乘算。射程/角度、弹数/散布、蓄力时间、回程时机/伤害、连锁数量/距离和场范围/时间由真实攻击读取；主属性、等离子、弹反伤害不附送改装系数。扩域近战的地面边界与动作扫掠同步，弹体与引力场沿用物理碰撞和掩体视线。

## 持久化边界

新战役写 run schema 3，明确 cooperative 布尔值及每席 weapon_mod（空字符串或两种已知 ID）。旧 schema 1/2 继续读取；旧十二舱继续写原单人/双人 schema。旧程序会拒绝 schema 3，既有 Profile 的不可写保护阻止静默剥离改装后覆盖。设备编号仍不持久化。奖励候选保存稳定 stat ID，冷启动重建同一张卡，不消耗随机数；恢复角色时先放入改装 ID，再 equip 生成实际定义。档案仍是一份原子事务。

## 验证

`tests/weapon_mods.gd` 覆盖所有十八武器的两种实际伤害/掩体行为、排他性与目录不变、真实弹道/连锁/回程/引力范围、键盘选择、双人分席说明、奖励及路线的隔离磁盘续档、坏字段/未来版本保护与旧版读取。原有封顶奖励夹具现在也占用改装槽，再验证一/二个符文候选；烟测按 ID 选择伤害卡，不依赖首卡位置。原生视觉与完整回归结果记入交付文档；输入机器人与真人体验验收保持区别。

2026-09-14 验证：完整 33 套 28,771 项通过，原生改装 349 项通过。正常规则穿透速射枪与双人分裂弓均完成三十舱，战斗舱中位分别为 121.75 / 114.2 秒。分裂方案经真实整局检查修订为保留主弹、增加两枚 35% 侧弹、间隔增加 20%，并在构筑页分别显示主弹与侧弹伤害。原生压力重测 900 帧、P95 25.669 ms，未达到 25 ms 门槛；40 次重开与孤立节点回收通过。该性能项按用户允许跳过未通过测试的要求保留为未达标，不能据此声明全面性能验收完成。
