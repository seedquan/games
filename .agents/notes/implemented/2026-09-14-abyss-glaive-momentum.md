# 重返飞刃的去程蓄势

Status: implemented.

## 原因与取舍

0.26.1 同种子、正常成长三十舱中，刀锋 / 速射枪 / 重返飞刃的最终守卫分别为 83.1 / 85.8 / 48.9 秒，最终基础攻击和符文一致。刀锋与速射枪首守卫仍需 164.3 / 151.8 秒，因此不根据重返飞刃一条样本普遍提高守卫耐久。数据见 `builds/qa/guardian-0261-comparison.json`；机器人不代表真人难度。

主动回收应提供返回时机选择，但原重返飞刃在提前回收或瞬间撞墙时也立即获得完整三倍回程。0.27.0 保留 0.26.0 的输入、防误触与归属机制，为该改装恢复时间与威力的取舍：去程的 0–0.75 秒让回程倍率从 1 线性增长到 3。半程 0.375 秒为两倍；满程自动回收为三倍。普通回旋刃、短程快返和旧十二舱继续使用固定倍率。

所有转向共用 `begin_return()`，在转向时锁定倍率。撞墙也只获得已飞行时间的收益；回程持续时间和重复按键不能再次蓄势或乘算。仍需收回旧弹体才能重投，不改基础攻击、符文、共享技能、守卫耐久或存档格式。已有新版战役的安全点按保存的改装 ID 重建定义，即可使用该规则。

## 呈现与验证

飞刃旁的细弧显示已蓄势的比例；转向后保持实际锁定值。它是状态提示，碰撞仍沿用半径 21 的刃体。提示不闪烁，暂停冻结。构筑页标注“最大回程命中”，改装卡和操作指南说明早收更快、等满更重。

`tests/glaive_recall.gd` 扩展真实输入和碰撞验证：部分蓄势命中、实际掩体折返、满程、暂停、重复回收、双席输入与固定倍率武器。已有改装套件保留自动完整往返与冷续档；原生检查覆盖蓄势弧线、构筑和小窗口指南。前后战役必须同时启用 `--manual-recall`；漏加该参数的首轮已单独留为自动回程对照，不能当作主动回收的调校收益。最终计时与交付状态记录于 `docs/balance.md` 和 `docs/production-readiness.md`。
