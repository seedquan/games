# 深渊协议的铭牌标题与等宽仪表数字

状态：implemented
日期：2026-09-14

用户要求字体更符合游戏风格。标题使用庆科黄油体，HUD 数字使用 Oxanium 的 600 字重，正文继续使用 Noto Sans CJK。字形与空间站舱牌、仪表相呼应，展示字体只用于标题和奖励名。`Display.tres` / `Readout.tres` 显式引用本地 Noto 回退，保持 Mac / Windows 的中文覆盖。

初选 Chakra Petch 的 `tnum` 实际无效，十个数字宽度不等；改用实测等宽的 Oxanium，避免冷却计时横向晃动。原始字体均未改写，SIL OFL 全文随 ThirdPartyNotices 发放，旧 Noto Serif 展示资源从当前源树移除。上游与字体校验值记录在资源说明及本地 QA 来源清单。

验证采用真实字号的数字测量、838 字语料覆盖、现有设置/玩家服务/HUD 场景与原生渲染，不增加仅检查字体文件名的测试。压缩预览在项目外生成。字体变更后必须重新执行完整源码回归和双平台发行验证。历史 HUD 退出警告以及雷霆残影首次原生清理断言失败保留，后续成功不证明其原因。
