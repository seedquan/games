# 有限增援、守卫循环与两分钟战斗目标

状态：implemented

## 背景

用户希望每个战斗舱约两分钟且难度适中。0.13.0 正常数值输入机器人全程只有约五分半：普通/精英战斗舱中位数约 22 秒，守卫约 7 秒。主武器与符文已能形成构筑，短遭遇却没有足够的攻防循环。

## 决定

新版战役使用有限敌人预算：首舱 63 个、其他战斗舱 72 + 区域序号 × 4，精英另加 10；双人增加 5% 并向上取整。首批仍为三敌教学，此后每批最多六敌。近卫、混合与交叉火力交替，首舱从第三批才出现远程敌人。清完所有批次即领奖，没有最低通关时间或无限刷怪。

增援落点优先靠近约 650 单位战斗距离并彼此分散，避免远处角落堆叠和反复长距离追赶。保留完整 1.25 秒投送预警；任一玩家占据落点时改址并重新开始完整预警。清完一批给存活队员补修 2 点耐久，不越过上限、不自动复活。首领耐久调整为 14000 / 22000 / 32000 / 45000 / 61000，攻击伤害、前摇和弹速不变，原有区域攻击循环得到实际展示时间。

击杀废料按旧版该舱敌人数 × 6 的固定预算分配到全部敌人，以相邻整数商之差保留每一点余数。清舱、技术核心、商店价格与祝福数值不变，避免刷怪规模放大购买力。旧十二舱生成器保持旧敌人数、原首领耐久、原落点与无波间补修；不更改玩家已存属性。新版安全点仍恢复到本舱入口，按当前战斗调校生成敌人。

## 验证

合约检查覆盖有限批次、同时敌人数、逐敌击杀和总废料、重复领奖、两席补修、旧战役边界。状态机和发行自检仍消费每一批真实预警，使用 32 倍测试时钟快速清场；这类直接伤害夹具不作为游玩证据。

游玩机器人只发送输入、使用正常数值和真实碰撞。速射枪完整单人/双人均通关，20 个战斗/守卫舱中位数 106.6 / 108.45 秒，范围 79.9–137.0 / 78.2–150.8 秒；流程约 36.9 / 37.3 分钟，安全舱阅读和选购时间不计作战斗。刀锋通过第一大区，四个战斗舱 99.0 / 143.0 / 174.5 / 159.1 秒，近战与精英有更长耗时。它们不是所有构筑或真人难度的保证。

Mac 原生速射枪第一大区为 78.9 / 104.3 / 124.0 / 109.0 秒；416.3 秒游戏时钟与 416.15 秒物理步数一致，排除加速时丢步造成的虚假时长。计时夹具支持武器、区域范围和加速参数；蓄力武器按真实按住/释放输入，近战按其射程接敌。高倍率样本只作工程基线，真人与实体手柄专项继续按用户要求跳过。

守卫纯主武器打靶改测首区、终区及最终极端/双人构筑，并逐物理步推进主武器。完整输入游玩覆盖其余区域；不再重复五次同结构长靶场。射击与游玩报告分开，主武器独打不代表使用等离子、元素、控制和闪避增伤的实际战斗时长。

原生双人扩展地图压力检查 84 项通过，40 次重开无节点增长；2560×1600 输出、900 帧中位 16.673 ms、P95 21.744 ms、P99 32.819 ms。压力夹具先进入暂停再返回船坞，确保真正执行受状态保护的返回操作。加速游玩夹具退出前恢复正常时钟，再留真实 200 ms 给声音混音线程释放资源；实际游戏没有这些测试时钟修改。
