## Design Context

### Users
Mac 与 Windows 上使用键鼠或双手柄同屏游玩的中文动作游戏玩家。任务是驾驶维修机器人七号穿过五个区域、三十舱室，理解危险、选择装备与路线，完成对三百一十二名乘客的救援。

### Brand Personality
沉着、工业、有人情味。用户明确要求 production quality 和提升审美；保留既有工业科幻方向；用户要求成熟的游戏设置品质、明确全屏入口，并用原创 SVG 解决缺失的视觉素材。

### Aesthetic Direction
失联空间站：石墨灰金属、暖白标识、少量救援橙。环境大形体克制，人物及攻击保持清楚。中文标题使用 Noto Serif CJK 半粗体，功能文本用 Noto Sans CJK。保留武器元素的功能色，不让它们扩散到菜单装饰。

### Design Principles
1. 战斗时先看清人、弹体和攻击范围，再看场景。
2. 色彩表达用途：暖白为文字，橙为操作重点，敌方红橙为即时危险。
3. 用舱壁、检修道和设备建立场所感，避免无意义的全屏网格与圆环。
4. 信息按当前任务出现；技能名字、按键和冷却成组，减少重复提示。
5. 独立素材、清晰焦点、可关闭闪光与震动、可恢复存档属于完成度的一部分。
