# 深渊协议 · 地图生图 Prompt 包

先生成 **01 接驳防线**，选定画风后，把它作为其余图片的风格参考。下面十条可以分别整段复制，每条都包含尺寸。第一批是五个区域各一张探索战斗地图，加五张空的 Boss 场地；它们用于确定美术与空间布局，后续再扩展不同舱室变体。

## 尺寸怎么设置

| 项目 | 统一要求 |
| --- | --- |
| 每张地图目标尺寸 | **3200 × 2100 像素，宽 × 高** |
| 画幅 | 横向，**32:21**，每张只画一个完整场地 |
| 文件 | 优先 PNG 原图；不透明背景，不要聊天截图 |
| 游戏显示器目标 | 2560 × 1440；这是屏幕尺寸，地图允许超出屏幕并由镜头移动查看 |
| 视角 | 正上方正交俯视，地板没有透视收缩，北在上；不使用菱形等距投影 |
| 地图边缘 | 最外侧约 5% 留给可裁切的舱壁或背景，门和关键通路放在其内 |

**尺寸也要在生图工具的设置中选择。** 只在文字里写尺寸，有些工具仍会按默认大小出图。

如果工具支持自定义尺寸，直接选 **3200 × 2100**。如果只能选择比例，选 **3:2 横图和最高分辨率**；例如工具提供的 3072 × 2048 或 1536 × 1024 均可作为源图。3:2 与目标比例接近，收到后可以等比缩放并轻微裁切适配，不拉伸场景。不要仅靠放大导出数字来冒充原生细节。

地图里的通路宽度是布局目标，生图模型未必严格执行；接入时会核对实际可走区域。以下像素描述都以 3200 × 2100 目标画布为基准。

## 统一画风与生成顺序

这是发生在“穹灯”空间站的科幻救援游戏。空间站仍有生命维持系统工作，场景要有维修、运输、生活设施留下的痕迹。参考动作地牢游戏的回环、侧翼和战斗留白；美术采用原创手绘工业科幻，不加入希腊神庙等题材元素。

统一使用石墨灰金属、暖白陶瓷、克制的区域色、左上方柔光和短阴影。地面纹理保持安静，环境灯亮度低于未来角色和战斗特效。所有地图中的门、箱体、护栏要保持同样的比例。

生成第二张起，上传选定的第一张作为风格参考，并加这一句：

> 严格沿用参考图的俯视角、手绘笔触、材质、物体比例、光照方向和细节密度；采用下述新地图的布局与区域配色，生成同一游戏中的另一处场景。

## 选图和发回

先出 `01_docking_map.png`，可以生成两三张候选。优先选择通路清楚、空地充足、地板不抢眼的一张；如果第一张的俯视角不对，先修正视角再生成后续地图。

发原图文件，保留生图工具名称、使用的 prompt，以及 seed（工具提供时）。不必为压缩方便拼成九宫格；可以把多张原图放进同一个 ZIP。

这批图片是完整场景的美术与布局来源。接入 Godot 时还要按图建立碰撞、导航、门、出敌点，并把需要遮挡角色的设备拆成独立层；单张 PNG 本身不包含这些游戏数据。

不要现在分别重画一张“去设备地板”和一张“设备层”：独立生图容易让位置漂移。定稿后优先用同一原图局部编辑补地板、提取设备；所有派生层沿用 **3200 × 2100** 画布和原坐标。前景层需要真实透明通道，不能用画出来的棋盘格代替。
