# 五区域战役的成长与战斗基线

0.14.0 将新版战役调整为有限批次攻防，目标为每个战斗舱约两分钟。下方保留成长规则，更新守卫耐久和实战证据。

本轮目标是让第一项祝福就有明显效果，同时避免三十舱室中的连续成长变成指数膨胀。以下是工程基线与受控战斗证据；没有将自动测试、静止目标或输入机器人当作真人难度验收。

## 发现并修复的问题

- 原伤害祝福每次乘 1.25，二十次即为初始的 86.7 倍；第三十舱普通敌人耐久仅为首舱的 3.9 倍。新版保留前几次的强增益，限制后期单次增量和累计上限。
- 原移速每次乘 1.1，连续二十一次可超过安全点存档允许的 2000，正常获得的成长也会导致存档校验失败。新版限制新增移速与冲刺恢复，已有数值不回写削减。
- 原冰霜与电击 II、III 级只提高了对应分支不用的 `power`，升级实际无效；自带元素武器获得同元素 I 级符文也无提升。新版让等级作用于控制时间/电击伤害，并让自带元素与符文在**同一次**命中中合并等级，仍只增加一层状态。
- 速射武器可每三发刷新首领冻结；新版首领冰冻有独立 2.2 秒触发间隔。普通敌人保留容易控制的定位。
- 高伤、多弹丸与贯穿可以将旧汲取的每次命中上限乘许多次；高伤武器升汲取等级反而没有改善。新版加入每人独立回复储备，随等级从 4 提高到 6、8，按相同数值每秒补充。
- 后期有效祝福可以少于三项。真实商店每次可以同时购买调校与符文，因此这也是正常路径。新版只展示 1–3 个有用且不同的选项，安全点存档接受对应数量；不会用无效卡片补数。

## 新版规则

| 成长项 | 实际行为 |
| --- | --- |
| 锋刃增幅 | 当前伤害 +25%，每次最多 +13，新增伤害上限 156；首项从 26 增至 32.5 |
| 商店调校 | 当前伤害 +15%，沿用每次 +13 与 156 的上限 |
| 修复矩阵 | 最大耐久 +25，新增容量上限 350；立即回复 45，按实际缺血计算 |
| 相位疾行 | 移速 +10%，新增移速上限 420；冲刺冷却 ×0.85，新增改善下限 0.45 秒 |
| 冰霜 I / II / III | 普通敌人冻结 1.80 / 2.25 / 2.70 秒；首领 0.60 / 0.72 / 0.84 秒，三次命中触发 |
| 电击 I / II / III | 普通敌人硬直 0.22 / 0.28 / 0.34 秒；首领 0.100 / 0.125 / 0.150 秒；II / III 另加 24.3% / 61.2% 本次命中伤害，每目标间隔 0.8 秒 |
| 汲取 I / II / III | 回复实际直接伤害的 6% / 12% / 18%；最多储备 4 / 6 / 8 点，每秒补充同样数量，瞬间散弹共享储备 |
| 元素自带效果 | 与符文等级相加，最高有效 IV 级；保存的符文仍为 I–III 级，单次命中不重复叠层 |

为了避免出现最后只有 1% 提升的卡片，新增伤害不足 3 点或当前伤害的 6% 时不再提供该项；移速和冲刺冷却都不足 5% 改善时，相位不再出现。因此正常奖励可能在数值硬上限之前停止提供。已保存的选择仍按真实余量执行。满容量但有缺血时，修复矩阵仍可作为明确标注的治疗；满容量又满血时不再出现。

所有上限仅约束**新增收益**。高于新版上限的合法恢复值保持原样。版本一的十二舱战役保持原有祝福乘法、控制规则与汲取，不重算已保存的成长。十八武器的基础伤害系数、冷却、射程、弹丸数和蓄力规则没有变动。

## 元素组合的范围收益

新版战役在原反应伤害上加入范围收益。热冲击消耗冻结，对主目标与半径 150 内可见敌人各造成火焰命中伤害的 70%；毒素至少三层才可被火焰引爆，消耗全部毒层，对主目标与半径 185 内可见敌人各造成每层 18% 火焰命中伤害。这里的火焰命中伤害包含该次武器/蓄力伤害和火焰有效等级倍率。

此前同时附着火毒时，每次命中都会烧掉刚叠的一层毒，无法积蓄。现在前两层保留持续伤害，第三次命中才引爆；独立毒武器可以先叠六层，再让火焰队友产生更大爆燃。引力井可先聚怪，冰冻新星也可为任何火焰武器准备热冲击。致命火焰命中仍可引爆已存在的冻结或三层毒，但不会在死者上新叠状态。

范围从反应敌人的地面中心计算，匹配完整可见边界，并检查实物掩体。爆发只造成一次直接伤害，不再添加符文、汲取或递归反应；主目标不会被范围分支重复命中，友方不在目标集合中。首领 2.2 秒冻结抗性不因碎冰重置。版本一仍是原单目标反应与一层毒立即引爆，存档数值和格式不变。

`tests/element_reactions.gd` 使用静止高耐久目标隔离机制，并从十八武器的真实攻击路径验证触发。数值例：20 点火焰命中产生 14 点热冲击；三层毒产生 10.8 点爆燃，六层为 21.6 点。它们是额外的每目标反应伤害，非独立的正常难度通关证据。

## 0.18.0 弹反构筑

新版弹反返还一枚来弹，基础伤害为 `max(来弹伤害, 防御者基础攻击)`；例如初始 26 点，调校至 78 后返弹为 78，遇到 90 点来弹则保留 90。它不额外乘刚获得的超载 50%，不继承武器穿透、爆炸和蓄力系数。之后通过正常命中入口应用自带元素和符文；汲取使用同一回复储备，范围反应不重复吸血。

返弹保持接触位置与原绘制高度，沿来路飞回，速度为原速的 1.8 倍且至少 620，1.25 秒后回收。每次 0.18 秒弹反窗口只返还一枚，其他同时到达的弹体由原有无敌保护。掩体挡住返弹和近身冲击波，友方不受伤；区域危险不可弹反。旧十二舱保留原规则。

镜头震动随机数与战斗随机数分离，额外画面帧不会再改变随后敌人的初始攻击冷却或武器散布。此处没有改变它们的分布，也没有把这一修复当作整个物理战斗跨帧率完全确定的证明。正常数值、不同武器的持续游玩仍需单独观察。

本版正常数值长枪输入机器人（seed 314159、逐物理步输入、12 倍模拟）首舱 88.3 秒，第二舱战斗约 101.1 秒后阵亡，未完成六舱目标。总游戏时间 189.336 秒、物理时间 189.517 秒，相差 0.181 秒；记录为失败样本 `builds/qa/lance-0180-physics-input.json`。该机器人只对近身前摇使用弹反，没有针对来弹设计防御策略，不能拿它代表返弹熟练玩家；也不能由此忽略近战生存需要继续检查。机制专项通过与正常战斗是否适中分开记录。

## 验证方法与结果

`tests/balance.gd` 禁止玩家正式存档读写。成长样本使用正常祝福入口；经济样本是可出现的奖励顺序与实际舱室收入、物品价格构造的保守账本，不是完整输入游玩。打靶样本通过真实主武器、真实弹体碰撞与正常冷却击杀目标；目标使用实际战役耐久，但暂停其移动/进攻来隔离武器吞吐量。

最后一个硬上限样本故意重复调用伤害奖励到上限，只验证极端成长边界，**不是声称能在正常选项中拿到二十九次伤害祝福**。它与前面的普通构筑、正常数值输入机器人及真人体验分别记录。

0.14.0 受控检查 931 项通过。长靶场保留首区、终区、极端与双人构筑，逐物理步推进主武器；完整输入游玩覆盖五个区域。2026-09-12 的成长修复基线为 937 项通过，旧首领耐久对应的耗时不再作为当前版本的证据。十商店账本完成 15 次购买，余额 1960，最少只剩 1 项有效祝福。

测试还覆盖真实元素作用、首领冰冻恢复窗口、同元素合并、汲取散弹爆发/一秒补充、旧版行为、双人各自收益、九种选择偏好的二十九次奖励序列和十商店经济路径。机器可读记录位于忽略的 `builds/qa/balance.json`。安全点 1–3 候选的真实写盘/重读由 `tests/reward_checkpoints.gd` 单独验证。

这些结果证明成长不会无界扩张、无效升级已经修复，并为难度迭代提供可重复的基线。真实玩家的瞄准、走位、选路、近战风险和两人配合会改变实战时长与伤害承受；仍需要 Windows 实机、实体双手柄和真人试玩反馈来判断最终难度与节奏。
